设计理念 — Liquid Glass

iOS 7 以来最重大的视觉重设计，融合光学玻璃的折射、反射与流体动态感

🌊

动态透明

UI 元素实时折射底层内容，随滚动和交互动态变化，营造物理真实感

🛠

深度与层次

光线弯曲（lensing）、高光、自适应阴影构建视觉深度，元素悬浮于内容之上

📄

内容优先

控件收缩变形以突出内容（Tab Bar 滚动折叠），减少 UI 对内容的遮挡

🌐

跨平台统一

iOS、iPadOS、macOS Tahoe、watchOS、tvOS、visionOS 共享 Liquid Glass 语言

SwiftUI 组件参考 — iOS 26

Liquid Glass 效果、新 Tab Bar 结构、玻璃按钮等 iOS 26 新增 API

Liquid Glass 效果

.glassEffect() 修饰符，放在 modifier chain 最后

// 基础玻璃效果 Text("Hello").padding().glassEffect() // 指定形状 Text("Hello").padding() .glassEffect(.regular, in: .rect(cornerRadius: 16)) // 带色调 Text("Hello").padding() .glassEffect(.regular.tint(.blue))

玻璃按钮 & 容器

新增 .glass / .glassProminent 按钮样式

// 半透明按钮 Button("Cancel") { } .buttonStyle(.glass) // 不透明主按钮 Button("Submit") { } .buttonStyle(.glassProminent) // 分组玻璃元素 GlassEffectContainer { HStack { Button("A") { }.glassEffect() Button("B") { }.glassEffect() } }

新 Tab Bar 结构

替代已废弃的 tabItem，支持滚动折叠

TabView(selection: $selectedTab) { Tab("Feed", systemImage: "list.star", value: 0) { FeedView() } Tab(role: .search) { SearchView() } } .tabBarMinimizeBehavior(.onScrollDown) .tabViewBottomAccessory { NowPlayingView() }

导航栏 & 新修饰符

WebView、@Animatable、scenePadding 等

// 原生网页嵌入 WebView(url: URL(string: "https://apple.com")!) // 导航副标题 .navigationSubtitle("3 items") // 搜索栏折叠 .searchToolbarBehavior(.minimize) // 场景级 padding .scenePadding() // 自动 Animatable @Animatable struct MyModifier: ViewModifier { var progress: Double }
